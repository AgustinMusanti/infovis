---ACLARACIÓN DE LOS DATOS DEL TP---

Los datos de uso de Claude vienen en un archivo JSON que incluye el contenido completo de cada conversación. 
Como ese contenido tiene información personal que no quiero exponer públicamente, procesé el archivo y me
quedé solo con los metadatos (fechas, horarios, cantidad de mensajes, longitud de texto) sin incluir ningún
contenido de las conversaciones. 
Además, los datos estan separados en 2 archivos porque tienen granularidad distinta (uno es por conversación 
y el otro por mensaje)
